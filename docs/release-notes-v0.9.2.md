# NeoSonia v0.9.2 Release Notes

2026-11-06。相对 v0.9.1 的修复与改进。

## 本版重点

### 复制与新建对话
- **桌面端**：代码块右上角新增复制图标（只复制纯代码，不含语言标签/零宽字符）；每条助手回复底部新增「复制完整回复」图标（非流式时显示，复制整段回复原文）。
- **网页端同步**：代码块复制改为图标按钮（成功变勾 1.5s）；助手消息底部新增「复制完整回复」图标（流式结束后出现）；列表页「新对话」改为 `+` 图标按钮，手机单栏/宽屏双栏一致。

### 设备管理
- **修复桌面端设备重命名不生效**：远程服务运行时 `devices.json` 的权威状态在 WebServer 内存里的 `DeviceStore`，桌面端旧实现直接写文件会被内存状态覆盖，且列表来自内存 → 改名看似无效（网页端走 API 所以正常）。
  - 现在桌面端重命名走 `WebServer::rename_device`（与远程 API 同一个 store），Web 未启用时退化为文件级重命名。
  - 重命名成功后刷新设备列表；名称长度桌面/网页统一为 **1-32 字符**，并加实时 `N/32` 计数器。

## 兼容性
- 配置/数据格式与 v0.9.1 兼容，直接覆盖安装即可；`config/`、`data/`、`workspace/`、`skills/` 不会被安装包覆盖。
- 本发布包不含任何用户数据/密钥。

## 验证基线
`cargo test --workspace` 全绿；安装包静默安装/卸载、「应用和功能」条目、图标与 VERSIONINFO 均实测。
