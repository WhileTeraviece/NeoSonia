# NeoSonia v1.0.0 Release Notes（草案，待验收后发布）

2026-11-06。

## 本版重点

### 即时存档与恢复（新增）
- 模型可把文件存入安装目录下的备份区（`backups/`）：`snapshot_save`、`snapshot_list`、`snapshot_restore`、`snapshot_delete` 四个工具。
- 每个原始路径对应一个快照：新版本备份**覆盖**旧版本（version 自增）；`snapshot_restore` 校验 SHA-256 后把文件放回原位置。
- 备份区对模型**只读**：普通读写/删除/移动工具不能修改备份区；命令中引用备份区目录会被拒绝执行；`snapshot_*` 是唯一写入/删除入口。

### 计算机使用
- `screen_mark`：在真实屏幕上渲染指定坐标的定位标记（十字/编号，鼠标穿透、自动消失），辅助精准点选。
- `mouse_graph`：按输入函数 y=f(x) 在指定定义域内移动鼠标，可按住左/右键；支持 `dry_run` 预演采样点。

### 界面
- 历史页：说明文字左端对齐；返回箭头移到右上角；新建对话 `+` 移到「会话 (N)」行最右侧。
- 设备页：移除「返回设置」按钮；刷新改为右上角图标按钮。

## 兼容性
- 与 v0.9.3 配置/数据兼容；`config/`、`data/`、`workspace/`、`skills/` 不被安装包覆盖。
- 本发布包不含任何用户数据/密钥。

## 验证基线（发布前填写）
`cargo test --workspace` 全绿；安装包静默安装/卸载、图标与 VERSIONINFO 实测。
