# NeoSonia v1.0.0 Release Notes

2026-11-06。首个 1.0 版本。

## 本版重点

### 即时存档与恢复（新增）
- 模型可把文件存入安装目录下的备份区（`backups/`）：`snapshot_save`、`snapshot_list`、`snapshot_restore`、`snapshot_delete` 四个工具。
- 每个原始路径对应一个快照：新版本备份**覆盖**旧版本（version 自增）；`snapshot_restore` 校验 SHA-256 后把文件放回原位置。
- 备份区对模型**只读**：普通读写/删除/移动工具不能修改备份区；命令中引用备份区目录会被拒绝执行；`snapshot_*` 是唯一写入/删除入口。读取允许。

### 计算机使用
- `screen_mark`：在真实屏幕上渲染指定坐标的定位标记（十字/圆环/编号，鼠标穿透、自动消失），辅助精准点选；支持 `dry_run` 只算坐标。
- `mouse_graph`：按输入函数 y=f(x) 在指定定义域内移动鼠标，可按住左/右键；支持 `dry_run` 预演采样点。

### 界面
- 历史页：说明文字左端对齐；返回箭头移到右上角；新建对话 `+` 移到「会话 (N)」行最右侧。
- 设备页：移除「返回设置」按钮；刷新改为右上角图标按钮。
- 邮件页：刷新收件箱改为图标按钮（头部与未配置引导里）。

### 安装 / 卸载
- 卸载改为由安装目录里的 `neosonia.exe --uninstall` 完成（「应用和功能」和开始菜单「卸载 NeoSonia」都指向它），不再单独生成 `Uninstall.exe`：部分安全软件（如 Kaspersky）会拦截/隔离「解压后立即自删除的卸载器」，导致卸载按钮无法启动或文件被删。
- 卸载时删除注册表项与快捷方式，并由分离的 cmd 进程在应用退出后删除安装目录（含配置/数据）。

### 修复
- 设备重命名（v0.9.2）：桌面端改名走 WebServer 的 DeviceStore，不再被内存状态覆盖；名称校验统一 1-32 字符。
- `screen_mark` 握手修复：叠加层显示成功后才返回，避免建窗错误被吞、UI 显示完成但屏幕无标记。

## 兼容性
- 与 v0.9.3 配置/数据兼容；`config/`、`data/`、`workspace/`、`skills/` 不会被安装包覆盖。
- 本发布包不含任何用户数据/密钥。

## 验证基线
- `cargo test --workspace`：app 76 / core 130 / mail 108 / tools 145 / web 99 / mcp 34，全绿。
- 快照真机 E2E：写入 → 备份 → 修改 → 恢复 → 读回原内容，manifest 哈希一致。
- `screen_mark` 真机截图可见坐标标记；`mouse_graph` dry_run sin(x) 120 点无异常。
- 安装包静默安装/卸载、「应用和功能」条目、图标与 VERSIONINFO 均实测。
