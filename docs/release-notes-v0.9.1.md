# NeoSonia v0.9.1 Release Notes

2026-11-05。相对 v0.9.0 的修复与改进。

## 本版重点

### 人设编辑（本版主要修复）
- **正文可滚动**：人设正文改为固定高度外框 + 内层滚动（框不动、字在框内滚），滚到最底最后一行完整可见；外框 padding 在滚动容器内，框内任意位置滚轮都生效。
- **点击定位光标**：修复 fenestra 多行输入 `input_local` 把指针 y 固定成输入框中线的 bug；现在点正文哪一行，光标就落在那一行对应位置。
- **去掉"框里的框"**：改用 core `raw_text_area`（不再套 kit `text_area` 的边框/焦点描边），正文区只保留编辑卡外框。

### 邮件
- 新邮件到达时自动刷新邮件列表（poller 的 `NewMail` 事件触发 `MailRefresh`）。
- 「刷新」按钮修复：先取 bridge/proxy 再置 loading，避免 `loading` 永久卡 true 导致刷新被静默忽略；并使用 bridge 的实时配置而非 UI 快照（换账号后不会继续拉旧邮箱）。
- 列表拉取改为「完整头 + 正文前 1KB」，Outlook 40 封从 36–44s 降到 18–22s；列表按 UID 降序（最新在最前）。
- `SELECT` 后显式 `NOOP`，新增耗时/`newest_uid` 日志。

### 构建/安装
- 安装包与 release 包版本 0.9.1；自解压安装包内嵌卸载程序、安装位置可选（浏览目录）、注册「应用和功能」。
- exe 内嵌多尺寸图标与 VERSIONINFO（资源管理器/任务栏/文件属性正常显示）。

## 兼容性
- 配置/数据格式与 v0.9.0 兼容，直接覆盖安装即可；`config/`、`data/`、`workspace/`、`skills/` 不会被安装包覆盖。
- 本发布包不含任何用户数据/密钥。

## 验证基线
`cargo test --workspace` 全绿；安装包静默安装/卸载、「应用和功能」条目、图标与版本信息均实测。
