# NeoSonia v0.9.3 Release Notes

2026-11-06。相对 v0.9.2 的改进。

## 本版重点

### 历史页头部布局
- **「返回对话」改为 `←` 图标按钮**（tooltip「返回对话」），放在「历史」标题左侧，与邮件页返回按钮一致。
- 头部重排：「历史」标题 + 说明文字在左；「新建对话」`+` 图标固定在右上角；整体顶部对齐，操作区不再挤在说明文字旁，阅读更舒服。
- 加载中「搜索中」spinner 仍在标题右侧；`history-back` / `history-new` 行为不变（覆盖层关闭历史 / 独立历史页切回对话）。

## 兼容性
- 与 v0.9.2 完全兼容，直接覆盖安装即可；`config/`、`data/`、`workspace/`、`skills/` 不会被安装包覆盖。
- 本发布包不含任何用户数据/密钥。

## 验证基线
`cargo test --workspace` 全绿；安装包静默安装/卸载、「应用和功能」条目、图标与 VERSIONINFO 均实测。
