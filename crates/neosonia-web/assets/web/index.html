连不上？点这里查看排障步骤

当前访问地址：—

当前用的是 127.0.0.1 / localhost，手机无法访问这个地址。请在桌面端「远程访问」页刷新二维码，改用 http://192.168.x.x:端口 这样的局域网地址。

  1. 确认手机和电脑连接同一个 Wi-Fi（不要用移动数据或访客网络）。
  2. 确认二维码/访问地址里是 192.168.x.x 这类局域网 IP，而不是 127.0.0.1。
  3. Windows 防火墙首次会拦截：允许「NeoSonia」专用网络访问；或在管理员 PowerShell 里放行端口：
    netsh advfirewall firewall add rule name="NeoSonia Web" dir=in action=allow protocol=TCP localport=8787
  4. 关闭 VPN / 代理软件后重试（VPN 会改变路由，手机可能连不到电脑）。
  5. 部分路由器的「AP 隔离 / 访客网络隔离」会阻止同一 Wi-Fi 下的设备互访，需要在路由器设置里关闭。
  6. 仍不行：在电脑上打开 http://<局域网IP>:端口/healthz，能看到 JSON 就说明服务本身正常，问题在网络或防火墙。

配对码一次性有效，过期后请在桌面端刷新。

只接受同一局域网内的设备连接；token 只保存在本机浏览器里。
